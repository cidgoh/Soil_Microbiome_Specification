# The Soil Microbiome Data Specification

## About

A data specification for harmonizing soil microbiome contextual data to improve data quality, data integration, and analysis, supporting consistent and reusable data across research and monitoring initiatives.

## Overview

Soil microbiome research is expanding across Canada, driven by growing interest in soil health, sustainable agriculture, biodiversity, and ecosystem resilience. Numerous research programs and monitoring initiatives are collecting soil samples and generating microbiome data, but these efforts are often conducted using different sampling protocols, contextual data conventions, and measurements, making it difficult to compare results across studies or integrate datasets at provincial or national scales.

Important contextual information such as soil composition, moisture, land management practices, or sampling conditions is often inconsistently recorded or omitted entirely. This limits the ability to compare microbiome datasets across studies, integrate data into larger monitoring or research programs, interpret microbial community data in relation to environmental drivers, and support reproducible, reusable soil microbiome research.

This project is developing a contextual data specification for soil microbiome samples that harmonizes core contextual data across studies. The specification defines core contextual fields describing soil samples, environmental conditions, physico-chemical properties, biological context, and sample lifecycle management. By aligning with existing soil and environmental metadata standards, including the [MIxS (Minimum Information about any Sequence) Soil package](https://genomicsstandardsconsortium.github.io/mixs/) from the Genomic Standards Consortium, the specification aims to support interoperability across research programs, agricultural monitoring initiatives, and national soil observation efforts.

**Aims:**

- Enable consistent, interoperable, and reusable soil microbiome data by aligning existing standards around a shared, practical framework for describing soil samples and their context.
- Improve how soil microbiome data are described and shared by making contextual data more consistent, clear, and comparable across projects and organizations.
- Support the combination, analysis, and interpretation of soil microbiome data beyond the original study.
- Align with existing standards rather than replace them; build on current approaches so they work together more effectively.

## What are ontologies and how do they improve data quality?

Labs collect, encode and store information in different ways. They use different fields, terms and formats, they categorize variables in different ways, and the meanings of words change depending on the focus of the organization (think of the word "plant": to someone in agriculture, "plant" could mean an organism that carries out photosynthesis, while a food regulator might understand "plant" to mean a factory where food products are made). This variability makes comparing, integrating, and analyzing data generated by different organizations like trying to compare apples, oranges, and bananas — difficult to do.

Ontologies are collections of controlled vocabulary arranged in a hierarchy, where all terms are linked using logical relationships. Ontologies are open source and meant to represent a "universal truth" as much as possible, rather than being tied to any one organization's vocabulary or use case. Ontologies encode synonyms, which enables mapping between the specific languages used by different organizations, and every term is assigned a globally unique and persistent identifier. Using ontology terms to standardize soil microbiome contextual data not only helps make data more interoperable by using a common language, it also helps make contextual data FAIR (Findable, Accessible, Interoperable, Reusable).

## The Soil Microbiome Specification Package

This specification is being developed and will be implemented via a spreadsheet-based data collection instrument (metadata template), accompanying Field and Term reference guides (providing definitions and additional guidance), and a curation Standard Operating Procedure (SOP). New terms and/or term changes will be requestable using issue request forms, with guidance outlined in a New Term Request (NTR) SOP. These resources will be made available in this repository and listed under [Package Contents](#package-contents) as they are developed.

## Version Control

Please note that development of the specification is dynamic and it will be updated periodically to address user needs. Versioning is done in the format x.y.z:

- x = Field-level changes
- y = Term value / ID level changes
- z = Definition, guidance, example, formatting, or other uncategorized changes

Descriptions of changes will be provided in [release notes](https://github.com/cidgoh/Soil_Microbiome_Specification/releases) for every new version.
