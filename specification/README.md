# Specification Files

This folder contains the Soil Microbiome Specification in two formats.

| File | Description |
|------|-------------|
| soil_microbiome_spec_v0.1.csv | View in browser as a table |
| soil_microbiome_spec_v0.1.xlsx | Download for use in Excel |

The specification defines standardized fields for contextual data associated with soil microbiome samples. See the [docs/ folder](../docs/) for full documentation.
